# 地籍共作平台

讓測量員外業回來，把**重測系統的資料夾**丟上來，大家就能在同一張地圖上看到彼此的**補點、參考點**，並對照**數值地籍圖**與整理過的**圖根點**。

- 不用安裝任何套件：只要一台裝了 **Python 3.8 以上** 的電腦當「主機」，其他人用瀏覽器打開網址就能用。
- 資料都存在主機的 `data/` 資料夾，不會傳到外面（只有底圖圖磚會向國土測繪中心要；沒網路也能用，只是沒有底圖）。

## 一、架設（管理者做一次就好）

1. 主機安裝 Python 3（<https://www.python.org>，安裝時勾 **Add python.exe to PATH**）。
2. 把整個專案資料夾放到主機上，例如 `D:\地籍共作平台`。
3. 把轄區的數值地籍圖（例如 `115-11-01數值.zip`，或解開後的 `KC0308`、`KC0309`… 資料夾）放進 `data\base\`。
   - 沒有 `data\base` 就自己建一個；也可以開平台後在 **⚙ 管理 → 更新數值地籍圖** 上傳。
4. 雙擊 **`啟動平台.bat`**。第一次會整理底圖（82 段大約 10 秒），視窗會顯示網址，例如：
   ```
   http://192.168.1.23:8080
   ```
5. 把這個網址給大家（可以做成桌面捷徑或書籤）。視窗不要關，關了平台就停了。

> 換埠號：`啟動平台.bat --port 9000`；資料放別處：`啟動平台.bat --data E:\平台資料`
>
> Windows 防火牆第一次會問要不要允許 Python 連線，請選「允許（私人網路）」。

## 二、測量員：上傳外業資料（3 步）

1. 按綠色 **📤 上傳外業資料**，填名字（第一次填就會記住）。
2. 把重測系統的資料夾（例如 `383` 或 `KC1114`）**整個拖進框框**，或按「選資料夾」／「選檔案 / zip」。
3. 看系統讀到的內容（補點幾點、參考點幾點、圖根點有沒有不符），沒問題按 **✅ 上傳**。

系統會自己挑需要的檔案，其他的（NTX、MTX、xls…）自動略過：

| 檔案 | 讀出什麼 |
|---|---|
| `KCxxxx.D20` | **補點**（CTL_LEVEL 是 Q 或點名 Q 開頭）；不是 Q 的當成「測量員新增控制點」 |
| `KCxxxx.D14` | **參考點**（COT_REF 編碼不是 00 的點，顯示成 `5.30` 這種點號） |
| `KCxxxx.L02`、儀器 `.CSV` | 這次用到的**圖根點**，會跟 .CTL 整理結果比對，差超過 2 公分（可調）就警告 |
| `*.B90` | **協助指界計算**：記錄「由哪個測站、後視哪點、測到哪個補點」，地圖上畫綠色虛線 |
| 沒有 D20／D14 時 | 退而用 `L20`（補點）、`L14`（編碼非 0 的參考點） |

- `KC0000.L02` 是重測系統預設檔，會略過。
- 資料夾外面、看不出段別的檔（例如 `11304161.CSV`），上傳內容只有一個段時會自動歸到那段。
- 同一個人、同一段再傳一次，**新的蓋掉舊的**；舊的上傳紀錄還在「🕘 誰上傳了什麼」，可以下載原始檔或刪除。
- 兩個人上傳同名補點但坐標差超過容許值 → 地圖上那點會**閃爍**，點開看得到兩人的坐標。

## 三、查詢

- **🔍 查詢**：一個框框什麼都能打
  - 地號：`123`、`123-4`、`123之4`、`1114 123-4`（段代碼 + 地號）
  - 點名：`QW1`、`BHC339`（打開頭幾個字就好）
  - 測量員名字：列出他的上傳
- 地圖點一下任何東西都會跳出說明；**📋 複製坐標** 可以貼到其他程式。
- 右下角可以勾選要顯示哪些圖層、換底圖、只看某個人的資料。
- 放大到一定程度才會出現圖根點（15 級）和地籍線（16 級），地號文字在 18 級。

## 四、圖根點（.CTL）為什麼要「整理」

轄區 82 段的 .CTL 合起來 85,332 行，但實際只有約 13,500 個點，而且很亂：

| 問題 | 數量 | 平台怎麼處理 |
|---|---|---|
| 同一點在很多段重複出現 | 大部分 | 合併成一點，記錄出現在哪些段 |
| **同名不同點**（例如 `A1`、`A10` 在不同地區代表不同的點，相距好幾公里） | 1,834 個點名 | **用「點名＋坐標」分群**，相距 10 公分以上就當不同點，編成 `A1#1`、`A1#2`，點開會提醒 |
| 同一點各段坐標差一點點（例如差 1.7 公分） | 334 | 取出現最多次的坐標，並標示最大差值 |
| 假設坐標（例如 `Q5A 3182.303 5000.000`） | 9 | 不放到地圖上，列在問題清單 |
| X 坐標是 0 | 1 | 同上 |
| 點名裡夾 tab、點名剛好 8 字和 Y 黏在一起（`QHB186-1`、`L129+580`） | 少數 | 依固定欄寬讀取（點名 8、Y 11、X 10、註記 2） |

**⚙ 管理** 裡可以看問題清單（點一下就飛到那點），也可以下載整理後的圖根點 CSV。

## 五、資料放在哪

```
data/
  base/            數值地籍圖（放 zip 或 KCxxxx 資料夾）
  cache/           自動產生的底圖快取（刪掉會重建）
  uploads/         每次上傳的原始檔（1.zip、2.zip…）
  platform.sqlite  上傳紀錄與點位
  config.json      設定（坐標系統、容許差、段名對照）
```

**備份只要複製整個 `data` 資料夾。** `data/` 不會進 git（地籍資料不該放上 GitHub）。

## 六、開發

```
python -m unittest discover tests     # 測試
python server/app.py --port 8080      # 啟動
```

- `server/parsers.py`：所有檔案格式的讀取（參考「土地重測資料轉換系統」的規則）
- `server/basemap.py`：數值地籍圖 → 每段一個 JSON、圖根點整理
- `server/app.py`：HTTP 伺服器、SQLite
- `web/`：網頁（Leaflet 1.9.4 已內附，不用連外網）
